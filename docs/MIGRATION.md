# Installing Arch on hardware

Back up the virtual machine before installing on hardware. Follow the official
[Arch installation guide](https://wiki.archlinux.org/title/Installation_guide)
and [dual boot guide](https://wiki.archlinux.org/title/Dual_boot_with_Windows).
Installers, disk layout, encryption and bootloader choices are your responsibility.

Copy your personal files through SSH or external storage. Reinstall packages
with pacman and configure the new machine normally. There is no bundled
distribution importer or curl-to-shell migration command.
